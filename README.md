# Państwa-miasta

Logiczna gra słowna. Zawiera trzy poziomy kategorii, kilka wariantów rozgrywki, lokalną bazę odpowiedzi oraz animowane podsumowania rund.

Strona: [panstwa-miasta-balbina.netlify.app](https://panstwa-miasta-balbina.netlify.app)

## Uruchomienie

```bash
pnpm install
pnpm dev
```

## Sprawdzenie projektu

```bash
pnpm lint
pnpm test
pnpm build
```

## Prywatność

Gra nie wymaga konta i nie wysyła odpowiedzi użytkownika na zewnętrzne serwery. Ustawienia, statystyki oraz rozpoczęta rozgrywka są przechowywane lokalnie w przeglądarce.
